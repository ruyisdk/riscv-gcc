### 该目录包含 GNU 编译器套件（GCC）。

GNU 编译器套件是自由软件。有关复制权限，请参阅以 `COPYING` 开头的文件。。手册及部分运行时库适用不同条款，具体细节请参阅各源文件。

目录 `INSTALL` 以 HTML 和纯文本格式存放了安装说明的副本。该信息的源文件为 `gcc/doc/install.texi`。安装说明包含 GCC 源码包内容构成及安装文件详情的具体说明。

请查看文件 `gcc/doc/gcc.texi`（以及它包含的其他文件）以获取使用和移植信息。在线可读版手册存放于`gcc/doc/gcc.info*` 系列中。

如何有效提交错误报告请访问：http://gcc.gnu.org/bugs/

GCC 源文件的版权年份可能采用区间表示法（例如 1987-2012），表示该区间内每一年（含首尾年份）均为可单独列出的可版权保护年份。
